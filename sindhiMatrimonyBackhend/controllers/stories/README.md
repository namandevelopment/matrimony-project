# 💑 Controllers: Success Stories (`controllers/stories/`)

## 🎯 Kaam aur Zimmedari (Work & Responsibilities)
Sindhi Vivah success stories registry aur testimonials gallery.

## 📄 Expected Files
- `index.js`: Module barrel exporter.
- `admin.js`: Story moderation, photo crop/watermark, wedding date verify, publish toggle.
- `users.js`: Bride & Groom dwara shaadi ki story submit karna, public stories browse karna.

## ⚙️ Key Actions & Flows
1. **Couple Submission**:
   - Wedding photos aur story text upload karna.
2. **Admin Verification**:
   - Profile matching verification ke baad story ko public portal par publish karna.
