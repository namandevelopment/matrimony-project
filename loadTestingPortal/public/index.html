🛡️ AegisLoad Portal & Cyber Attacks Knowledge Hub

A comprehensive architectural reference guide explaining how high-scale load testing works, common web vulnerabilities, denial of service attacks, and production hardening strategies.

⚡

Portal Architecture & Methodology

AegisLoad Studio utilizes native Node.js keep-alive socket pooling, high-precision performance timers (`perf_hooks`), and Server-Sent Events (SSE) to generate up to 200,000 parallel requests without crashing browser memory.

✓ Keep-alive connection pooling
✓ Sub-microsecond latency resolution
✓ Native V8 memory profiler
💣

Layer 7 Volumetric HTTP Floods

Attackers fire tens of thousands of requests per second to saturate the application server's CPU and exhaust thread pools. Without rate limiters, web servers crash within seconds.

🛡️ Mitigation: Dual-Layer Rate Limiting (Redis token bucket + in-memory fallback) returning sub-0.1ms HTTP 429.
📱

OTP Exhaustion & SMS Billing Drain

Malicious bots repeatedly request OTPs on randomized phone numbers to drain third-party SMS gateway funds (MSG91/Twilio) and trigger vendor account suspensions.

🛡️ Mitigation: Strict 5 OTP / 10 min window per phone/IP + pre-registration account checks.
💾

Database Write Lock Cascades

When thousands of users submit redundant profile updates simultaneously, MongoDB write locks queue up, causing latency to spike from 10ms to over 5,000ms.

🛡️ Mitigation: Strict Rule 4.4 `isDataEqual` (fast-deep-equal) skips 100% of redundant DB writes in < 2μs.
🛑

Node.js Event Loop Starvation

Node.js runs on a single main thread. If one synchronous function executes heavy loops or blocking crypto (`bcrypt.hashSync`), ALL concurrent users freeze simultaneously.

🛡️ Mitigation: 100% async/await non-blocking design + PM2 Multi-Core Cluster mode across all CPU cores.
📈

Understanding P50 vs P95 vs P99

Average latency is deceitful because a few fast queries hide slow ones. P95 latency guarantees that 95% of real users experience sub-50ms speed, eliminating frustrating app lag.

🎯 SLA Target: P50 < 15ms | P95 < 50ms | P99 < 250ms under peak load.
