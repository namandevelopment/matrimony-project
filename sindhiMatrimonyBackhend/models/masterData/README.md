# 🏛️ Models: Sindhi Master Data (`models/masterData/`)
- `religion.model.js`: Religion taxonomy.
- `caste.model.js`: Caste catalog.
- `subcaste.model.js`: Sindhi Subcastes (Amil, Bhaiband, Sahiti, Shikarpuri, etc.).
- `gotra.model.js`: Gotra catalog.
- `surname.model.js`: Sindhi Surnames mapped to Subcastes and Gotras.
- `compatibilityRule.model.js`: Cultural Gotra exogamy and match compatibility rules.
