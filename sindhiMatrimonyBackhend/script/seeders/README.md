# 🌱 Database Seeders (`script/seeders/`)
- `runSeeder.js`: Master execution script jo sabhi seeders ko sequence me run karta hai.
- `seedSuperAdmin.js`: Default Super Admin account create karta hai agar exist na karta ho.
- `seedMasterData.js`: Sindhi community ke official Castes, Subcastes, Gotras aur Surnames seed karta hai.
- `seedPlans.js`: Default Free, Silver, Gold, aur Diamond Assisted plans seed karta hai.
