# 📢 Models: Marketing Campaigns (`models/campaigns/`)
- `notificationCampaign.model.js`: Push/SMS/WhatsApp blast campaigns metadata.
- `recipientDeliveryLog.model.js`: Per-user delivery status (SENT, DELIVERED, OPENED, FAILED).
- `festivalOffer.model.js`: Discount coupons aur promotional discount rules.
- `inAppPopup.model.js`: Mobile app dynamic splash/modal announcements.
