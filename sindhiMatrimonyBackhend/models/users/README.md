# 👥 Models: Members & Candidates (`models/users/`)
- `user.model.js`: Primary user account (phone, email, passwordHash, status, accountType).
- `profile.model.js`: Comprehensive matrimonial candidate profile (7-step onboarding data, bio, physical attributes, family).
- `partnerPreference.model.js`: Candidate's desired partner criteria (age range, height range, gotras, education).
- `userPhoto.model.js`: Candidate photo gallery with privacy levels (PUBLIC, BLURRED, PRIVATE).
